# agent-review-audit 对比与融合计划（2026-08-11 评审）

## 姊妹技能位置与结构

- 路径：`~/.gemini/antigravity-cli/builtin/skills/agent-review-audit/`（用户 Antigravity/Gemini CLI 的内置 skill，与本技能并行）
- 结构：SKILL.md（4.4KB 轻量路由表，6 大类）+ `references/03_Cards/Q001~Q243.md`（243 张题卡，~1MB）+ `scripts/route_project.py`（3.8KB，关键词路由）
- 题源同族：243 卡与本题库 240 题同源（如 Q006≈L9），可做 Q↔L 映射

## 题卡 schema（它比我们强的部分）

frontmatter 字段：`qid / title / primary_category / sub_category / depth_level / status(待复习) / tags / concepts / prerequisites / downstream`
正文：`[!QUESTION]` 问题描述 + `[!NOTE]` 元数据与知识上下文 + `[!SUCCESS]` 答题思路与知识点分析

- 每卡内嵌**答题思路与知识点分析** —— 题目和答案一体，语料自带蒸馏（本技能 items.json 缺这一层）
- `prerequisites/downstream` —— 学习路径有向边（真图谱）
- `status: 待复习` —— 间隔复习种子

## route_project.py 路由机制与局限

- 机制：6 类关键词频次打分（×2/命中）→ 取最高类目 → 固定返回该类目 cards 列表前 3 张
- 局限：只到**类目级**（非题级/概念级）；路由表只覆盖约 50/243 张卡，八成题卡不可达；无语义匹配；无证据文件；`os.walk` 无跳过目录/大小限制（大仓库会慢）；无复盘/薄弱优先

## 对比结论

- 它强在**知识组织**：卡内嵌答案、学习路径边、复习状态
- 本系统强在**项目闭环**：概念级路由（match.json + 证据文件）、项目内作答（文件:行号 锚点）、三维评分、复盘、薄弱优先
- 交互互补：它审代码（架构对齐/坑点预警/演进建议 三维），本系统审人（概念理解/原理深度/落地证据 三维）
- 它的完整性缺陷：题卡里 `[[01_Agent架构与设计范式]]` 等分类 wikilink 全部断裂（references/ 只有 03_Cards，无分类笔记）
