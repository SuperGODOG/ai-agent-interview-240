# 项目档案：SuperGODOG__skillforge

> 来源：https://github.com/SuperGODOG/skillforge ｜ Commit：`2426d7b` ｜ 分支：`linux` ｜ 工作树状态：Dirty (4 modified files) ｜ 文件 136 个 ｜ 语言 Python

## 一、 项目定位与核心价值
SkillForge 定位为**“生产 Skill 的元 Agent 工厂”**：打造一套让 Skill 本身可评测、可版本管理、可自动修复与持续演进的工程化闭环系统。针对大模型自主生成代码或工具时常见的“Prompt 越改越差（跷跷板效应）”、“无界递归重试击穿预算”、“多存储状态不一致”等行业痛点，提出了结构化、防御性的工程约束。

## 二、 真实技术栈与代码/测试事实
- **核心语言与基建**：Python 3.11+ / Pydantic (类型与模式校验) / SQLite 3 (持久化与状态机) / Git (版本快照与差分)。
- **测试工程事实**：全量单元与集成测试 `pytest` 74/74 全部通过。
- **框架边界事实**：
  - **主执行链**：采用高可控确定性循环 (`src/skillforge/evolution_loop.py` / `evolver.py`)。
  - **LangGraph 定位**：作为**受控回环旁路 Shadow 版** (`src/skillforge/langgraph_loop.py`)，复用核心算子用于状态图编排演进验证与 Durable SQLite 检查点断点续跑，**不取代主执行链**。
  - **排除范围**：源码为纯 Python AI Agent 系统，不包含任何底层 CUDA C/C++ 算子实现，亦无 Java 高并发/秒杀业务逻辑。

## 三、 核心架构模块与代码实现证据
1. **SkillRegistry 渐进式披露与元数据标准** (`src/skillforge/registry.py`, `models.py`)
   - 规范 Skill YAML 前置头与 Markdown 指引，通过 `use_skill` 显式归因调用，实现渐进式上下文加载，大幅降低上下文窗口占用。
2. **IntentRouter 三层级联路由** (`src/skillforge/router/cascade.py`, `rule.py`, `embed.py`, `llm.py`)
   - 规则前置（Rule-first 零成本硬拦截）→ 语义向量检索（Embedding 召回 Top-K 候选）→ LLM 兜底仲裁（大模型处理模糊歧义意图），提供完整的意图评估评测体系 (`router/evaluation.py`)。
3. **SkillEvaluator 评测门禁、Pairwise Judge 与防退化棘轮** (`src/skillforge/evaluator/`)
   - P0 门禁 (`p0_gate.py`) 强拦截致命缺陷；Pairwise Judge (`judge.py`) 采用配对比较对抗绝对打分漂移；Ratchet 棘轮机制 (`ratchet.py`) 确保新版本在多维指标上不劣于旧基线，杜绝“修 A 坏 B”。
4. **Repair 局部受控修复与 6 层归因层次** (`src/skillforge/repair.py`, `receipt.py`)
   - 严格区分 6 层责任归属：`skill` / `tool` / `policy` / `planner` / `evaluator` / `unknown`，仅对 `skill` 层触发受控 Patch；通过 `ValidationReceipt` 产生可操作的确定性诊断凭据与有界预算（max_attempts=2）。
5. **ReleaseStateMachine SQLite 发布状态机** (`src/skillforge/state_machine.py`)
   - 落实 ADR-06 唯一事实源，严格遵循 4 步原子写入协议：Git commit → SQLite PREPARING → JSONL 追加 → SQLite PUBLISHED；内置 24h Watchdog 清理孤儿状态，UUID v4 保证幂等。
6. **Three-Tier Memory 三层记忆架构** (`src/skillforge/memory.py`)
   - 严格物理与语义隔离：Semantic Memory（事实/冲突保留）、Episodic Memory（经验/执行轨迹）、Procedural Memory（技能/程序记忆），评测专用轨迹绝不泄露至候选学习。
