# Q471: 状态循环转移中奖惩抵消机制与终局奖励等价性辨析：若模型从商品 A 切换到 B 再切回 A，中间的探索奖励与返回惩罚在数值上相互抵消，是否就等价于“只依据最终状态决定奖励”？从势能塑形（Potential-based Shaping）、累积步成本与折扣因子的角度，两者的本质区别是什么？

> - **抵消辨析**: 核对按状态变化还是过程累计奖励，再看折扣、步数成本和终止奖。
> - **等价性结论**: 即使单次来回抵消，因存在步数消耗与折现损耗，不能直接证明等价终局奖励。
