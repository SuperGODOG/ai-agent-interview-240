> [!SUCCESS] 通用参考与审查要点
> - **公平基准构建**: 必须包含充分 Warmup、动态刷新 Cache 防止缓存命中偏差、采用 GPU 侧精确时钟测量纯 Kernel 耗时。
> - **指标与归因**: 结合硬件理论峰值算力和带宽测算 MFU/HFU，利用 Roofline 模型区分算子是计算受限（Compute-bound）还是访存受限（Memory-bound）。
